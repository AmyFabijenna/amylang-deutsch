Die vier Fälle

Fortgeschrittene Übungen für die Gymnasiumsvorbereitung

Teil 1: Übersicht und Regeln

Die vier Fälle (Kasus) im Deutschen:

1. Nominativ – Wer oder was? → Das Subjekt
2. Genitiv – Wessen? → Besitz, Zugehörigkeit
3. Dativ – Wem? → Empfänger, indirektes Objekt
4. Akkusativ – Wen oder was? → Direktes Objekt
Fall Frage Maskulin Feminin Neutrum Plural
Nominativ Wer/Was? der / ein die / eine das / ein die / –
Genitiv Wessen? des / eines (+s) der / einer des / eines (+s) der / –
Dativ Wem? dem / einem der / einer dem / einem den (+n) / –
Akkusativ Wen/Was? den / einen die / eine das / ein die / –
⚠️ Häufige Fallen:
• Feminin: „der" kann Genitiv ODER Dativ sein!
• Maskulin: Nur hier ändert sich der Akkusativ (der → den)
• Genitiv: Das Nomen bekommt oft -s oder -es (des Mannes, des Kindes)
• Dativ Plural: Die Nomen bekommen meist -n (den Kindern, den Häusern)

Teil 4: Präpositionen und ihre Fälle

Präpositionen verlangen bestimmte Fälle:

Immer Akkusativ: durch, für, gegen, ohne, um, bis, entlang
Immer Dativ: aus, bei, mit, nach, seit, von, zu, gegenüber
Immer Genitiv: wegen, trotz, während, innerhalb, außerhalb, statt
Wechselpräpositionen: in, an, auf, unter, über, vor, hinter, neben, zwischen
(Wo? → Dativ / Wohin? → Akkusativ)

Teil 5: Adjektivendungen in allen Fällen

Adjektivendungen nach bestimmtem Artikel:

Die Endung ist meist -e oder -en.
-e: Nominativ (m/f/n) und Akkusativ (f/n)
-en: Genitiv (alle), Dativ (alle), Akkusativ (m), Plural (alle Fälle)

Diese Verben brauchen ein Dativobjekt:

Zusammenfassung – Prüfungswissen

Fall Frage Maskulin Feminin Neutrum Plural
Nominativ Wer/Was? der / ein die / eine das / ein die
Genitiv Wessen? des (+s) / eines der / einer des (+s) / eines der
Dativ Wem? dem / einem der / einer dem / einem den (+n)
Akkusativ Wen/Was? den / einen die / eine das / ein die
Die wichtigsten Regeln:

✓ Nominativ = Subjekt (Wer tut etwas?)
✓ Genitiv = Besitz (Wessen?) + nach: wegen, trotz, während, innerhalb
✓ Dativ = Empfänger (Wem?) + nach: aus, bei, mit, nach, seit, von, zu
✓ Akkusativ = direktes Objekt (Wen/Was?) + nach: durch, für, gegen, ohne, um
✓ Wechselpräpositionen: Wo? → Dativ, Wohin? → Akkusativ

Geschafft! Wer diese Übungen beherrscht, ist bereit fürs Gymnasium.
