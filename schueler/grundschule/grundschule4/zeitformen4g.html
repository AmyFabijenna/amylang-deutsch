🕐 Stufe 1: Präsens (Gegenwart) LEICHT

🔍 Das Präsens - Die Gegenwart

Wann verwenden? Für etwas, das JETZT passiert!

Beispiele:
• Ich spiele Fußball. (jetzt)
• Du liest ein Buch. (jetzt)
• Er läuft schnell. (jetzt)

✏️ Übung 1: Erkenne das Präsens!

1. Der Hund bellt laut. → Welche Zeitform?
2. Lisa singt ein Lied. → Welche Zeitform?
3. Die Kinder spielen Ball. → Welche Zeitform?
4. Wir essen Pizza. → Welche Zeitform?
5. Die Sonne scheint hell. → Welche Zeitform?

🕑 Stufe 2: Präteritum (1. Vergangenheit) LEICHT

🔍 Das Präteritum - Die 1. Vergangenheit

Wann verwenden? Für etwas, das FRÜHER passiert ist!

Beispiele:
• Ich spielte Fußball. (gestern/früher)
• Du lasest ein Buch. (gestern/früher)
• Er lief schnell. (gestern/früher)

💡 Merke:

Präteritum oft bei Märchen: "Es war einmal..."
Häufige Formen: war, hatte, ging, kam, sagte

✏️ Übung 2: Erkenne das Präteritum!

1. Der Hund bellte laut. → Welche Zeitform?
2. Lisa sang ein Lied. → Welche Zeitform?
3. Die Kinder spielten Ball. → Welche Zeitform?
4. Wir aßen Pizza. → Welche Zeitform?
5. Die Sonne schien hell. → Welche Zeitform?

🕒 Stufe 3: Perfekt (2. Vergangenheit) LEICHT

🔍 Das Perfekt - Die 2. Vergangenheit

Wann verwenden? Beim Sprechen über die Vergangenheit!

Bildung: haben/sein + Partizip

Beispiele:
• Ich habe Fußball gespielt.
• Du hast ein Buch gelesen.
• Er ist schnell gelaufen.

💡 Merke:

haben oder sein + Partizip (ge...t oder ge...en)
• spielen → gespielt
• laufen → gelaufen

✏️ Übung 3: Erkenne das Perfekt!

1. Der Hund hat gebellt. → Welche Zeitform?
2. Lisa hat ein Lied gesungen. → Welche Zeitform?
3. Die Kinder haben Ball gespielt. → Welche Zeitform?
4. Wir haben Pizza gegessen. → Welche Zeitform?
5. Die Sonne hat geschienen. → Welche Zeitform?

🕓 Stufe 4: Futur (Zukunft) LEICHT

🔍 Das Futur - Die Zukunft

Wann verwenden? Für etwas, das SPÄTER passieren wird!

Bildung: werden + Infinitiv

Beispiele:
• Ich werde Fußball spielen.
• Du wirst ein Buch lesen.
• Er wird schnell laufen.

💡 Merke:

werden + Grundform des Verbs
• ich werde, du wirst, er/sie/es wird, wir werden, ihr werdet, sie werden

✏️ Übung 4: Erkenne das Futur!

1. Der Hund wird bellen. → Welche Zeitform?
2. Lisa wird ein Lied singen. → Welche Zeitform?
3. Die Kinder werden Ball spielen. → Welche Zeitform?
4. Wir werden Pizza essen. → Welche Zeitform?
5. Die Sonne wird scheinen. → Welche Zeitform?

🎓 Zusammenfassung - Alle Zeitformen auf einen Blick

Die 4 Zeitformen - Übersichtstabelle

Zeitform Wann? Bildung Beispiel
Präsens Jetzt Grundform ich spiele
Präteritum Früher -te / Stammänderung ich spielte
Perfekt Vergangenheit haben/sein + ge...t/en ich habe gespielt
Futur Später werden + Grundform ich werde spielen

💡 Die besten Merktricks:

  • Präsens: Was passiert JETZT? → ich spiele
  • Präteritum: Was war FRÜHER? → ich spielte (oft in Märchen!)
  • Perfekt: Was ist PASSIERT? → ich habe gespielt (beim Sprechen!)
  • Futur: Was wird SPÄTER sein? → ich werde spielen

📝 Beispiel mit allen Zeitformen:

Präsens: Lisa liest ein Buch.
Präteritum: Lisa las ein Buch.
Perfekt: Lisa hat ein Buch gelesen.
Futur: Lisa wird ein Buch lesen.
