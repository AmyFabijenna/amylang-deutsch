🎯 Deutscher Passiv - Der komplette Guide

🔑 SCHRITT 1: Das Grundprinzip verstehen

AKTIV
Wer macht was?
Der Koch kocht die Suppe.
→
PASSIV
Was wird gemacht?
Die Suppe wird gekocht.
Grundformel: WERDEN + Partizip II

Transformation Schritt-für-Schritt:

  1. Objekt wird Subjekt: die Suppe → Die Suppe
  2. Verb wird zu Partizip II: kocht → gekocht
  3. Hilfsverb "werden" hinzufügen: wird
  4. Altes Subjekt optional mit "von": (vom Koch)

🔑 SCHRITT 2: Die Hilfsverb-Familien verstehen

🔴 WERDEN-Familie (Vorgangspassiv)

Präsens: wird
Präteritum: wurde
Konjunktiv I: werde
Konjunktiv II: würde
→ Beschreibt einen Vorgang

🟡 SEIN-Familie (Zustandspassiv)

Präsens: ist
Präteritum: war
Konjunktiv I: sei
Konjunktiv II: wäre
→ Beschreibt einen Zustand

🔑 SCHRITT 3: Wann kommt "worden"?

🎯 EINFACHE REGEL:
worden kommt nur bei zusammengesetzten Zeiten mit werden!
Perfekt, Plusquamperfekt, Futur II = sein + Partizip II + worden
Wichtig: Im Passiv IMMER "worden" (OHNE "ge-")
"geworden" gibt es nur im Aktiv ("Er ist alt geworden")

🔧 MODALVERBEN IM PASSIV - Alle Zeitformen (Klicken zum Öffnen/Schließen)

Besonderheit bei Modalverben:

Aktiv: Man muss die Suppe kochen.

Passiv: Die Suppe muss gekocht werden.

Formel: Modalverb + Partizip II + werden

Zeitform können müssen sollen dürfen wollen mögen
Präsens kann gefragt werden muss gefragt werden soll gefragt werden darf gefragt werden will gefragt werden mag gefragt werden
Präteritum konnte gefragt werden musste gefragt werden sollte gefragt werden durfte gefragt werden wollte gefragt werden mochte gefragt werden
Perfekt hat gefragt werden können hat gefragt werden müssen hat gefragt werden sollen hat gefragt werden dürfen hat gefragt werden wollen hat gefragt werden mögen
Konjunktiv II könnte gefragt werden müsste gefragt werden sollte gefragt werden dürfte gefragt werden wollte gefragt werden möchte gefragt werden
Modalverben Perfekt: "hat gefragt werden müssen" (nicht "ist")
∞ INFINITIV & PARTIZIPIEN - Verschiedene Formen (Klicken zum Öffnen/Schließen)
Form Bildung Beispiel Verwendung
Infinitiv Präsens gefragt werden Er hofft, gefragt zu werden. Mit "zu"
Infinitiv Perfekt gefragt worden sein Er scheint gefragt worden zu sein. Vorzeitigkeit
Partizip I Infinitiv + -end fragend die fragende Person
Partizip II ge- + Stamm + -(e)t/-(e)n gefragt die gefragte Person
Gerundivum zu + Partizip I zu fragend die zu fragende Person
Infinitiv Perfekt: "gefragt worden sein" (nicht "geworden sein")
📢 IMPERATIV - Befehle (selten im Passiv) (Klicken zum Öffnen/Schließen)
Form du ihr Sie
Imperativ werde gefragt! werdet gefragt! werden Sie gefragt!
Wichtig: Imperativ im Passiv ist sehr selten und meist ungebräuchlich. Man verwendet eher Umschreibungen.

🧠 Merkregeln & Eselsbrücken

🎯 Regel 1: Hilfsverb-Auswahl
WERDEN = Vorgang (etwas passiert)
SEIN = Ergebnis (etwas ist fertig)
🎯 Regel 2: "worden" vs. "geworden"
Im Passiv IMMER worden (OHNE "ge-")
"geworden" gibt es nur im Aktiv ("Er ist alt geworden")
🎯 Regel 3: Konjunktiv-Trick
Konjunktiv I: Immer wie Infinitiv (werde, sei)
Konjunktiv II: Immer mit Umlaut (würde, wäre)
🎯 Regel 4: Futur-Endungen
Futur I: endet mit werden
Futur II: endet mit worden sein
Perfekt/Plusquamperfekt: "worden" ist kürzer als "geworden" - wie die Vergangenheit, die hinter uns liegt
Futur I: "werden" kommt zweimal vor - einmal konjugiert, einmal als Infinitiv
Modalverben: Modalverb + Partizip II + werden (Infinitiv)

⚡ Häufige Fehler vermeiden

Fehler 1: "geworden" statt "worden" im Perfekt
Falsch: ist gekocht geworden
Richtig: ist gekocht worden
Fehler 2: Falsches Hilfsverb im Perfekt
Falsch: hat gekocht worden
Richtig: ist gekocht worden
Fehler 3: Futur verwechseln
Futur I: wird gekocht werden
Futur II: wird gekocht worden sein
Konjunktiv II Vergangenheit: "wäre gefragt worden" (nicht "würde gefragt worden sein")

🎯 Übungsbeispiele

✏️ GRUNDÜBUNGEN - Transformation üben (Klicken zum Öffnen/Schließen)

Aktiv → Passiv Transformation:

  1. Aktiv: Der Lehrer erklärt die Aufgabe.
    Passiv: Die Aufgabe wird (vom Lehrer) erklärt.
  2. Aktiv: Die Schüler haben die Hausaufgaben gemacht.
    Passiv: Die Hausaufgaben sind (von den Schülern) gemacht worden.
  3. Aktiv: Man wird das Problem lösen.
    Passiv: Das Problem wird gelöst werden.
  4. Aktiv: Der Koch kochte die Suppe.
    Passiv: Die Suppe wurde (vom Koch) gekocht.
  5. Aktiv: Sie hatten den Brief geschrieben.
    Passiv: Der Brief war (von ihnen) geschrieben worden.
🎓 FORTGESCHRITTENE ÜBUNGEN - Schnell-Check (Klicken zum Öffnen/Schließen)
Welche Form ist das?
1. "wird informiert" = Präsens Passiv
2. "ist informiert worden" = Perfekt Passiv
3. "würde informiert" = Konjunktiv II Gegenwart
4. "wäre informiert worden" = Konjunktiv II Vergangenheit
5. "sei informiert worden" = Konjunktiv I Vergangenheit
6. "wird informiert worden sein" = Futur II Passiv
7. "kann informiert werden" = Modalverb Präsens
8. "war informiert worden" = Plusquamperfekt Passiv

🏆 Zusammenfassung

Passiv = werden (konjugiert) + Partizip II + (eventuell weitere Hilfsverben)

Einfache Zeiten

Präsens: wird + Partizip II

Präteritum: wurde + Partizip II

Zusammengesetzte Zeiten

Perfekt: ist + Partizip II + worden

Plusquamperfekt: war + Partizip II + worden

Zukunft

Futur I: wird + Partizip II + werden

Futur II: wird + Partizip II + worden sein

Konjunktiv

Konjunktiv I: werde/sei + ...

Konjunktiv II: würde/wäre + ...

Modalverben

Formel: Modalverb + Partizip II + werden

Beispiel: kann gekocht werden

Komplexitätsgrad

1. Einfach: Präsens/Präteritum

2. Mittel: Perfekt/Modalverben

3. Schwer: Konjunktiv, Futur II
