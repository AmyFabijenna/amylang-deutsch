📚 Nominalisierung - Theorie

1. Verb → Nomen

Verben werden zu Nomen umgewandelt, oft mit Suffixen wie -ung, -tion, -heit:

trainieren → das Training / die Trainierung
diagnostizieren → die Diagnose / die Diagnostizierung

2. Adjektiv → Nomen

Adjektive werden mit -heit, -keit, -ität zu Nomen:

fit → die Fitness
steril → die Sterilität

3. Nebensatz → Präpositionalphrase

Konjunktionen werden zu Präpositionen:

weil → wegen + Genitiv
obwohl → trotz + Genitiv
bevor → vor + Dativ
nachdem → nach + Dativ

4. Modalverben

Modalverben werden zu abstrakten Nomen:

können → die Fähigkeit / die Möglichkeit
müssen → die Notwendigkeit / die Pflicht
dürfen → die Erlaubnis / die Berechtigung

5. Funktionsverbgefüge (FVG)

Einfache Verben werden zu Nomen + Funktionsverb:

entscheiden → eine Entscheidung treffen
operieren → eine Operation durchführen
kritisieren → Kritik üben an

6. Komplexe Umformungen

Mehrere Transformationen gleichzeitig anwenden:

Obwohl der Athlet intensiv trainierte, gewann er nicht.
→ Trotz intensiven Trainings gewann der Athlet nicht.
