📖 Nominalisierung - Theorie & Regeln

1. Verb → Nomen

Verben werden mit verschiedenen Suffixen nominalisiert:

forschen → die Forschung (-ung)
analysieren → die Analyse (Stamm)
verhalten → das Verhalten (Infinitiv)

Häufige Suffixe: -ung, -heit, -keit, -nis, -tion, -ment, -e

2. Adjektiv → Nomen

wichtig → die Wichtigkeit
sicher → die Sicherheit
wirksam → die Wirksamkeit

3. Nebensatz → Präpositionalphrase

weil/da → wegen/aufgrund + Genitiv
Weil er krank war → Wegen seiner Krankheit
obwohl → trotz + Genitiv
Obwohl es riskant war → Trotz des Risikos
wenn/falls → bei + Dativ
Wenn Fehler auftreten → Bei Auftreten von Fehlern
bevor → vor + Dativ
Bevor man speichert → Vor dem Speichern
nachdem → nach + Dativ
Nachdem man prüfte → Nach der Prüfung
indem/dadurch dass → durch + Akkusativ
Indem man verschlüsselt → Durch Verschlüsselung
damit/um...zu → zu/zur/zum + Dativ
Um Daten zu schützen → Zum Schutz der Daten

4. Modalverben nominalisieren

können → die Fähigkeit / die Möglichkeit
müssen → die Notwendigkeit / die Pflicht
dürfen → die Erlaubnis / das Recht / die Berechtigung
sollen → die Pflicht / die Verpflichtung
wollen → der Wille / die Absicht

5. Pronomen → Possessivattribut

er prüft → seine Prüfung
sie analysiert → ihre Analyse
wir implementieren → unsere Implementierung

6. Funktionsverbgefüge (FVG)

Verben werden durch Nomen + Funktionsverb ersetzt:

entscheiden → eine Entscheidung treffen
kritisieren → Kritik üben an
beeinflussen → Einfluss nehmen auf
berücksichtigen → in Betracht ziehen
anwenden → zur Anwendung bringen/kommen
informieren → in Kenntnis setzen
