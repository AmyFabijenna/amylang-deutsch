🔑 Claude API Konfiguration ?

Wie bekommt man einen Claude API-Schlüssel?

Schritt 1: Account erstellen bei Anthropic
  • Gehe zu: console.anthropic.com
  • Registriere dich mit E-Mail-Adresse
  • Bestätige die E-Mail
Schritt 2: API-Zugang einrichten
  • Zahlungsmethode hinzufügen (Kreditkarte erforderlich!)
  • API-Schlüssel generieren unter "API Keys"
Schritt 3: Kosten beachten
  • Claude API ist kostenpflichtig (Pay-per-use)
  • Ungefähr $3-15 pro 1 Million Tokens
  • Eine Bewertung kostet ca. $0.01-0.03
