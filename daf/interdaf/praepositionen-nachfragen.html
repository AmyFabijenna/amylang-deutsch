Dabei, danach, darauf, auf ihn

Zeitangaben kürzer sagen, nachfragen und kurz antworten.

Teil 1: Zeitangaben. Sagen Sie es kürzer.

beim … → dabei  ·  nach dem / nach der … → danach  ·  vor dem … → vorher oder davor
Das neue Wort steht an derselben Stelle wie die Zeitangabe.
Ich muss jetzt das Mittagessen kochen. Beim Kochen höre ich immer Musik. → Dabei höre ich immer Musik.

    Teil 2: Fragen Sie nach.

    Sache → wo(r)- + Präposition: Worauf? Wovon? Worüber?
    Person → Präposition + Fragewort: Auf wen? Mit wem? Von wem?

      Teil 3: Antworten Sie kurz.

      Sache → da(r)- + Präposition: darauf, damit, dabei, dafür …
      Person → Präposition + Pronomen: auf ihn, mit ihr, an sie …
