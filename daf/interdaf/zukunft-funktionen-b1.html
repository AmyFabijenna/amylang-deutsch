SO KÖNNTE ES AUCH SEIN! Ordnen Sie die Sätze – klicken Sie die Wörter in der richtigen Reihenfolge.
Klicken Sie ein Wort im Wortkasten → es wandert in die Satzzeile. In der Satzzeile klicken → Wort geht zurück.
Futur 1: werden + Infinitiv (Endposition)  ·  wohl / wahrscheinlich / bestimmt / sicher drücken Vermutung aus.
2
Schreiben Sie Vermutungen – in zwei Formen!
Schauen Sie aus dem Fenster – es ist ein stürmischer Herbsttag. Was glauben Sie?
💡 Schreiben Sie beide Formen:
① dass-Satz (Präsens): gleich schneien → Ich glaube, dass es gleich schneit.
② Futur I mit wohl: gleich schneien → Es wird wohl gleich schneien.
3
Was ist das wohl für ein Mann? Schreiben Sie Vermutungen.
🖼️ Sie sehen einen Mann im Anzug mit Aktentasche am Bahnhof. Benutzen Sie: Ich glaube, dass er … oder Er wird wohl …
Beispiel (1): viel reisen → Ich glaube, dass er viel reist. / Er wird wohl viel reisen.
4
Formell oder informell? Ordnen Sie die Sätze zu.
Klicken Sie: A = In der Zeitung (formell)  ·  B = Unter Freunden (informell)
5
DAS MACHT NINA IN DER ZUKUNFT. Zukunft informell: Sätze im Präsens.
Benutzen Sie sie (= Nina). Achten Sie auf die richtige Wortstellung!
💡 Für informelle Zukunft benutzt man das Präsens + Zeitangabe: Morgen trifft sie sich mit Freunden.
Beispiel (1): morgen: ihren Arzt anrufen → Morgen ruft sie ihren Arzt an.
6
NACHRICHTEN. Zukunft formell: Sätze im Futur 1.
Formulieren Sie offizielle Nachrichten wie im Radio oder in der Zeitung.
💡 Futur 1 = werden + Infinitiv
Beispiel: Am kommenden Montag • die Präsidentin • im Parlament sprechen → Am kommenden Montag wird die Präsidentin im Parlament sprechen.

1
Welche Funktion hat werden? Kreuzen Sie an.
Klicken Sie die richtige Funktion: 🔵 Prozess · 🔴 Passiv · 🟡 Zukunft / Vermutung
🔵 Prozess = Veränderung / Entwicklung: Er wird krank. / Sie wird Ärztin.
🔴 Passiv = etwas wird getan (+ Partizip II): Das Auto wird repariert.
🟡 Zukunft / Vermutung = (+ Infinitiv): Es wird regnen. / Sie wird wohl kommen.
2
Ergänzen Sie die Verben – und bestimmen Sie die Funktion.
① Schreiben Sie den vollständigen Satz. ② Klicken Sie die Funktion von werden. ③ Dann Lösung prüfen.
💡 Passiv = werden + Partizip II  ·  Zukunft = werden + Infinitiv  ·  Prozess = werden allein konjugiert
3
Prozess oder Passiv? Klicken Sie die richtige Funktion.
Jedes Paar hat einen Prozess- und einen Passivsatz. Bestimmen Sie beide.
💡 Gibt es eine Handlung – etwas wird getan? → Passiv  ·  Gibt es nur eine Veränderung / Entwicklung? → Prozess
4
Schreiben Sie die Sätze im Perfekt – und bestimmen Sie die Funktion.
① Schreiben Sie den Perfektsatz. ② Klicken Sie Prozess oder Passiv. ③ Dann Lösung anzeigen.
🔵 Prozess: Er wird krank. → Er ist krank geworden.
🔴 Passiv: Er wird angerufen. → Er ist angerufen worden. (kein extra „ge-"!)
5
Ergänzen Sie worden oder geworden.
Wählen Sie die richtige Perfektform und klicken Sie.
💡 worden = Perfekt Passiv  ·  geworden = Perfekt Prozess
Wurde etwas mit jemandem / etwas gemacht (von jemandem)? → worden
